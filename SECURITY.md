# Security policy

## Supported versions

Hanoki is pre-alpha. Security fixes are provided only for the latest release.

## Report a vulnerability

Do not open a public issue for a suspected vulnerability. Use
[GitHub private vulnerability reporting](https://github.com/50BytesOfJohn/hanoki/security/advisories/new)
and include reproduction steps, affected versions, impact, and any suggested
mitigation.

Do not include real API keys, tokens, or personal chat data in the report.
You can expect an initial response within seven days.
